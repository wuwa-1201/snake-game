# 贪吃蛇 Snake Game

一个纯 HTML + Canvas 实现的贪吃蛇小游戏，无需任何依赖，打开即玩。

## 玩法

- **得分** = 吃到的食物数量
- 撞墙或撞到自己则游戏结束
- 最高分会保存在浏览器本地

## 操作

| 设备 | 操作 |
|------|------|
| 电脑 | 方向键 / WASD 控制方向，空格暂停，回车开始 |
| 手机 | 在游戏画面上滑动控制方向 |

## 在线试玩

## 技术栈

- HTML5 Canvas
- 原生 JavaScript（无框架）
- 移动端触屏滑动适配
